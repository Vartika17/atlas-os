# qwen3:8b — first portability test (2026-07)

**Setup:** Ollama 0.31.1, Windows 11 laptop (Ryzen 5 6600H, 16GB RAM, RTX
3050 4GB VRAM — hybrid offload). Compile test 01: full context chain,
~1,500-token compiled prompt, ~800-word content draft requested.

## Numbers

- Generation: 5.6 tok/s, 243s total for 1,145 output tokens (HTTP API,
  non-stream, num_ctx 8192).
- Interactive `ollama run` with prompt-as-argument HUNG indefinitely on
  Windows — use the HTTP API (`/api/generate`) for all scripted runs.

## Verdict: small tier confirmed, medium-tier work refused correctly

Ran deliberately below draft-content's `min_capability: medium`. Result
scored 5/12, Rework — the tier tags are real contracts.

**What it did well (honest small-tier capabilities):**
- Followed structure contract (H1/H2s, single CTA, no preamble)
- Used persona objections and positioning language correctly
- Argument order coherent

**Failure modes observed (expect these from any ~8B on judgment work):**
1. **Fabricated a statistic under specificity pressure** ("68% of
   consumers...") despite an explicit no-invented-numbers instruction. The
   taste rule "concrete beats abstract" pushes weak models to invent
   concreteness. Mitigation for small-tier compiles: drop the specificity
   taste section or add a hard scaffold ("every number must be quoted from
   FACTS or omitted").
2. **Persona-name leakage** — addressed the internal persona ("Farida,
   you're...") as the reader.
3. **Undershot length** (~65% of contract).
4. **Mild unearned claims** ("our systems are tested...").

## Standing guidance

- qwen3:8b on this hardware: use for small-tier tasks (extraction,
  reformatting, classification, summaries of provided text). Do not compile
  medium-tier patterns onto it expecting ship-grade output.
- Scripted runs: HTTP API only; PowerShell 5.1 callers must write output
  with explicit UTF-8 (`[IO.File]::WriteAllText` with UTF8Encoding) —
  default encodings corrupt em-dashes.
- Next test candidates: qwen3:4b (fits 4GB VRAM fully — likely ~3x faster,
  same tier) for speed; a ~30B class model when hardware allows, to test
  the medium tier locally.
